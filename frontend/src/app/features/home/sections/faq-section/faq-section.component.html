FAQs

Can I create more than one plan for the same month?

No. Each year-month can have only one monthly plan.

Can I change jar percentages?

Not in this version. The 7 default jars are fixed for the MVP.

How should I enter income?

Enter a positive whole VND amount (digits only).

What happens if I submit an existing month?

The system blocks duplicates and shows a message that the monthly plan already exists.

Can I use this app on mobile?

Yes. The home page and planning layout are responsive for smaller screens.

Who calculates budget amounts for each jar?

The backend API is the source of truth for all financial calculations.
